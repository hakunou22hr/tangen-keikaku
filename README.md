# 数学 指導と評価の計画ジェネレーター

高校数学の単元目標、3観点の評価規準、年間時数配分、各時間の指導と評価の計画を編集し、学校で利用できる Word 文書に出力する静的 Web アプリです。サーバーやデータベースを使用せず、GitHub Pages で公開できます。

## 主な機能

- 数学Ⅰの4領域（数と式、図形と計量、二次関数、データの分析）の目標・評価規準を表示
- 年間105時間の配分例を編集・保存
- 配当時数に応じて授業行を自動生成
- 評価場面を「空欄 → ○（形成的評価）→ ◎（総括的評価・記録に残す評価）」で切り替え
- 科目・単元ごとにブラウザーの `localStorage` へ自動保存
- `public/templates/unit-plan-template.docx` の表・罫線・配置を保ったテンプレート差し込み出力
- PCでは表、狭い画面では時間ごとのカードに切り替わるレスポンシブ表示

## 使い方

`index.html` を静的サーバーから配信してください。Word出力はブラウザーの `fetch` を使うため、ファイルを直接開くのではなく HTTP(S) での配信が必要です。

```bash
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。

## Wordテンプレート

正式なテンプレートは `public/templates/unit-plan-template.docx` です。基本情報・目標・評価規準のタグと、`{#lessons}`〜`{/lessons}` の繰り返し行を出力処理で差し替えます。テンプレートを変更する場合は、タグ文字列を分割する装飾を避けてください。

出力処理はブラウザー標準 API のみを利用し、外部ライブラリやインターネット接続を必要としません。

## 評価規準の根拠

データは、次の公的資料に示された数学Ⅰの内容、資質・能力の三つの柱、および観点別学習状況の評価の考え方に対応するよう、単元単位で整理したものです。資料本文の転載ではなく、授業計画で利用しやすい表現に再構成しています。学校の指導計画・生徒の実態に応じて確認・調整してください。

- 文部科学省「高等学校学習指導要領（平成30年告示）」
- 文部科学省「高等学校学習指導要領解説 数学編・理数編」
- 国立教育政策研究所「『指導と評価の一体化』のための学習評価に関する参考資料 高等学校 数学」
